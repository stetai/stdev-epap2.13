# StDev-Epap2.13
Show `.ical` events on an Epaper module produced by WeAct Studio with special adaptation to the ical format used for [Stedule](https://github.com/stetai/stedule.git).

Implements a progress bar counting down to the next events and highlighting of events marked as "Important".

Forked and detached from WeAct Studio Epaper Module.
